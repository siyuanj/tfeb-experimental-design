## 图谱方向注释的格式处理

只读检查到最终 GenBank 候选的 SV40/pUC origin 带 `no directional arrow assigned` 注释，而 GenBank 简单区间回读会得到 strand=+1（TSV 明确为 0）。报告图谱渲染器会优先尊重这条显式注释，不给这两个 origin 编造方向箭头；manifest 同时保留 parsed strand 和 displayed strand。没有修改主线 GenBank/TSV，也不把此格式差异认定为序列错误。
