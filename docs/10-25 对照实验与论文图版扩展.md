## 用户要求与当前范围

用户要求增加课程作业的实验设计工作量，写清各种对照，多画质粒，按论文风格排图；解释性小字放图注。用户要求在 GitHub 查找 Nature 风格配色并统一全文，允许使用未购买 SnapGene 的免费 Viewer 截图。

## 配色与呈现

采用 [ggsci NPG/nrc](https://github.com/nanxstats/ggsci/blob/37b74f85e62680b9d4523b0b4c0d9bfa0403d299/R/palettes.R)，固定提交 `37b74f85e62680b9d4523b0b4c0d9bfa0403d299`。这是受 Nature Reviews Cancer 启发的开放配色，不是 Nature 要求所有作者采用的官方标准。[作者文档](https://nanx.me/ggsci/reference/pal_npg.html)说明配色来源。

十色为 `#E64B35 #4DBBD5 #00A087 #3C5488 #F39B7F #8491B4 #91D1C2 #DC0000 #7E6148 #B09C85`。源码统一入口为 `scripts/B-figures/publication_style.py`。启动子用深蓝、TFEB 用绿色、EGFP 用青色、抗性用紫灰色、复制起点用棕色、突变用朱红色；同一图族颜色语义固定。正文保持黑色，模板已有彩色强调使用该色系。白底、无渐变，图中只保留元件、坐标、泳道、采样时间和必要分面编号；解释、对照意义及限制移入图注。

参考 [Nature figure guidance](https://www.nature.com/nature/for-authors/final-submission) 的统一字体、可读标签和矢量图原则。图谱保留 SnapGene 原生的 Verdana 字形，代码示意图采用 DejaVu Sans；没有把软件导出字形伪称为同一种字体。

## SnapGene 实测与替代方案

- 本机 SnapGene Viewer 8.2.3 无付费激活。命令行转换和预览返回“使用此命令前请先激活”。
- 免费 GUI 的“文件 → 输出 → 图谱”实际成功输出 PDF/SVG，无需截图或购买。五张质粒均已通过 GUI 导出；最大字号，隐藏无关限制酶标签。原生导出保留 `Created by SnapGene` 标识。
- 按[官方 GenBank–SnapGene 格式规范](https://support.snapgene.com/hc/en-us/articles/10242682237588-What-is-Genbank-SnapGene-Format)在派生展示文件中设置颜色和方向。完整序列不变，正文展示只挑选主要元件；完整注释仍保留在 `设计/controls-v2/`。
- `报告/质粒图-SnapGene/*-publication.svg` 是原生大字号输出；`*-en.svg/pdf` 仅将中文单位“碱基对”排为 `bp`，不改图形路径、位置、颜色或厂商标识。`*-native.svg` 是先前正常字号探索稿。
- 对比过 [DNA Features Viewer](https://github.com/Edinburgh-Genome-Foundry/DnaFeaturesViewer) 与 [Biotite plasmid map](https://www.biotite-python.org/latest/examples/gallery/sequence/annotation/plasmid_map.html)。当前圆图实际使用 SnapGene；Biotite 2.0.0 仅在忽略目录安装探索，不是最终渲染器。

## 实验与计算产物

五种质粒条件：pEGFP-N1、WT、S211A、S142A、S142A/S211A。WT 与三个突变体均 6134 bp、722 aa；GCC 是显式选择的 Ala 密码子，不声称优化。S142A 为 1054–1056 的 AGC→GCC；S211A 为 1261–1263 的 TCC→GCC，坐标 1-based。所有变体均由同一已验收 WT 派生；供体 FASTA 可用于计划合成，未采购或验证实物。

独立脚本 `scripts/B-audit/check_control_panel.py` 从原载体重新组装供体，逐字符检查核苷酸改变、独立密码子表翻译、连接肽/EGFP/末端 stop、酶切与显示坐标。旧 B-v1 输入及 sequence/methods ready 不变。

正文新增十一类对照问题、十二个实施模块、八周拟定安排。主要补充：匹配氨基酸/血清/溶剂，表达量梯度，内源 TFEB 与分级，时程/恢复，三类突变，RPTOR/RICTOR RNAi，14-3-3 co-IP，TFEB 敲低与 WT 救援，qPCR 与 paired-inhibitor LC3 turnover，毒性/特异性及重复统计。

七幅正文图：空载体与 WT、三个突变体、处理/恢复时程、证据结构、融合蛋白对比、克隆流程、预测 DNA 条带。旧精细全注释图和 ImageGen 历史稿保留，但不再用作本版正文图。

## 复算与验收

使用原课程 `.venv-plasmid/bin/python`。新排版库独立安装在本仓库忽略目录 `tools/figure-libs/`；版本固定于 `scripts/B-figures/requirements-publication.txt`，不修改课程环境。

依次运行 `build_control_panel.py`、`check_control_panel.py`、`prepare_snapgene_maps.py`；如果输入/颜色变了，重新在 SnapGene GUI 导出五个 `*-publication.svg`。随后运行 `render_publication_figures.py`、`render_accepted_map.py`、`render_pipeline_figures.py`、`compile_report.py`、`check_report_consistency.py`。实际逐页查看后更新视觉记录，再运行 `finalize_report.py`。

`publication-figures.json` 记录原生输出、展示输入、源码和最终图文件的哈希，并检查原生 SVG 元件用色在 NPG 色系内。完整图谱、供体、最终 PDF 和公开核查结果可追溯；大运行时、原文和核查页图不进入普通 Git。

## 未验证与剩余事项

没有湿实验成功率、显著性、实测 WB/定位图或效果量。确切 siRNA 和 qPCR 寡核苷酸尚未定稿；试剂、抗体性能、剂量、实际采样数需要执行前 pilot。RPTOR rescue、活细胞 export kinetics、串联 LC3 是满足特定因果或正交验证要求时的后续模块，不能声称已有设计序列。作者身份、实际贡献和课程最终要求仍由作者确认。旧 B-v1 P9 验收不自动覆盖本次新增细胞设计。
