## 本项目设置

```latex
\documentclass[a4paper,11pt,lang=en,math=cm,bibend=bibtex]{elegantpaper}
```

- `lang=en`：英文标题与图表标签；正文使用英文，作者暂用拼音。若以后保留中文姓名，需另行配置中文字体支持。
- `math=cm`：采用模板默认数学字体方案。
- `bibend=bibtex`：这是对官方默认 **Biber** 的有意调整，使 Tectonic 与 XeLaTeX + BibTeX 使用同一套报告源文件。参考文献仍由 `biblatex` 管理，数据保存在 `报告/references.bib`；不同时引入 `natbib` 或另一套文献系统。

官方支持 pdfLaTeX 与 XeLaTeX，并提供 BibTeX 后端选项。本项目约定 Tectonic 或 XeLaTeX + BibTeX 两条构建路径；具体命令见项目 README，真实构建结果见 STATUS，未运行的路径不视为已验证。

## 运行依赖

除 `elegantpaper.cls` 外，需要 LaTeX 运行时及 `biblatex`、BibTeX。XeLaTeX 字体分支使用 `fontspec` 和 TeX Gyre Termes/Heros；模板还会加载 `geometry`、`hyperref`、`graphicx`、`caption`、`booktabs` 等常用包。使用 Tectonic 时由其包资源提供相应依赖，构建前核对资源可用性。

本项目不要求合作者修改全局 TeX 配置。新增依赖或更换编译引擎时，先更新这里与 README，并在 STATUS 记录实际验证结果。
