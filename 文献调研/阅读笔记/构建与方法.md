## 1. 结论

**人 TFEB 荧光融合蛋白在 HeLa 细胞中的营养依赖定位，已有直接而成熟的原始研究。** 2012 年 Roczniak-Ferguson 等的 Figure 3 已比较饥饿、rapamycin、Torin1 并定量核/质荧光比；可直接支撑课程设计的可行性，但不能将相同设计表述为首次发现。2018 年研究已进一步做到营养恢复和核输出动力学。[Roczniak-Ferguson 2012](https://pubmed.ncbi.nlm.nih.gov/22692423/)、[Napolitano 2018](https://doi.org/10.1038/s41467-018-05862-6)

**历史 Word 提纲**有两项问题：① N 端 EGFP 方案与“删除 TFEB stop codon 以保持融合”的理由混用了两种构建方向；② `mTOR-dependent phosphorylation controls TFEB nuclear export` 的第一作者应是 **Napolitano**，不是 Li, Y.。**当前 LaTeX 已修正这两项，也已明确独立重复统计单位与定位不等于通量。** 仍待落实的是实际融合方向、带版本序列、接头、构建验证及具体实验条件；若扩展突变体，S211A 也不能简单定义为“始终完全位于细胞核”。

下表仅为可核查记录，不是选购或最终选型决定。Addgene 页面存在不等于我们已持有该质粒，也不等于完整序列已在本地验证。

| 记录 | 物种与标签方向 | 与本设计的关系 | 本次阅读层级 |
|---|---|---|---|
| [pEGFP-N1-TFEB，Addgene #38119](https://www.addgene.org/38119/)；Ferguson；Roczniak-Ferguson 2012 | 人 TFEB；**TFEB–EGFP，EGFP 在 TFEB 的 C 端**；pEGFP-N1；CMV；页面写明 deleted stop codon，旧参考号 NM_007162.2 | 有直接 HeLa 定位研究出处，优先作为对照参考。不能写成 N 端 EGFP–TFEB | 官方完整产品页；未下载/比对序列 |
| [pcDNA3.1-TFEBS211A-MYC (#805)，Addgene #99957](https://www.addgene.org/99957/)；Brugarolas；Vega-Rubin-de-Celis 2017 | 人 TFEB S211A；Myc 与 6×His 在骨架 C 端；无 GFP 标签 | 证明 S211A 试剂确有公开记录；不能直接当作荧光显微镜用的 TFEB–EGFP S211A | 官方产品页的物种、突变、标签字段 |
| [pCIP-Flag-TfebAA，Addgene #79014](https://www.addgene.org/79014/)；Shaw；Young 2016 | **小鼠** Tfeb；N 端 Flag；S142A/S211A | 不等同于人 TFEB–EGFP 双突变体。页面另提醒突变编号随 isoform 而异 | 官方完整产品页 |
| Park 等 2021 的 EGFP-tagged TFEB-L / pEGFP-C1 | 人全长 TFEB 插入 pEGFP-C1，作为 N 端 EGFP 构建实例 | N 端 EGFP 融合确有文献先例；该论文研究剪接变体，不构成“此方向优于 C 端融合”或“在我们 HeLa 条件已验证”的证据 | 原始论文 PMC 索引返回的方法段落；未逐页核读全部补充资料 |

Park 等的方法段明确描述把 TFEB-L 亚克隆到 pEGFP-C1。因此两个方向都存在，但我们当前最直接对应“人 TFEB + HeLa + 饥饿/Torin1 定位”的已存质粒是 C 端 EGFP 的 #38119。[Park et al. 2021](https://doi.org/10.1038/s41598-021-00613-y)

特别注意：部分论文把 #38119 在行文中称为 EGFP-TFEB，名称顺序未必严谨。应以官方标签字段、实际构建图与完整序列共同确认，不能只看短名称。当前 NCBI 可检索到 [NM_007162.3（transcript variant 1）](https://www.ncbi.nlm.nih.gov/nuccore/NM_007162.3)，而 #38119 沿用 NM_007162.2；本次没有比对两版 CDS，不能断言两者蛋白序列不同或完全相同。

## 3. 历史 Word 的 stop codon 问题：当前 LaTeX 已修正

原 Word 第 2.2 节选择 `CMV–EGFP–linker–TFEB`，并说删除 TFEB stop 以保持 EGFP–TFEB ORF 连续；第 2.4.1 节又要求 reverse primer 排除 TFEB 的 stop。**该历史解释与拟定方向不自洽。** 当前 `报告/sections/methods-cloning.tex` 已分别说明两个方向的终止密码子安排，并保持融合方向为 provisional，不再保留这一错误。

| 方向 | 连续翻译要求 | 最末端如何终止 |
|---|---|---|
| `EGFP–linker–TFEB`（N 端 EGFP） | EGFP 到 TFEB 的接头同框，接头之间不能有终止密码子 | TFEB 已是最后一个蛋白编码模块，通常保留 TFEB 自身 stop；若不保留，必须明确由下游哪一个同框 stop 终止以及有无额外氨基酸 |
| `TFEB–linker–EGFP`（C 端 EGFP） | TFEB 到 EGFP 的接头同框，不能在 TFEB 末端提前终止 | 删除 TFEB 自身 stop，让翻译进入 EGFP，再由融合 ORF 最末端 stop 终止；#38119 官方记录采用这种逻辑 |

这是对历史提纲的分子克隆逻辑审查，不是已经完成序列验证。删掉末端 stop 并不必然导致完全不能表达；具体后果取决于下游序列。当前 LaTeX 已正确要求核查完整序列、接头、阅读框与末端 stop；这些核查仍待实际序列固定后完成。

原 Word“选择 N 端 EGFP 可保护 C 端 DNA-binding and activation regions”的论据也不足；当前 LaTeX 已改为待核查的方向选择。TFEB 的 N 端本身含重要调控序列；Martina 与 Puertollano 2013 用 Δ30 和 S3A/R4A 等证明其 N 端参与 Rag 相互作用及溶酶体募集。**不能由此反推 N 端标签一定破坏功能，也不能假定 N 端标签天然更安全。** 本次文献结果支持继续保持当前 LaTeX 的谨慎表述。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3575543/)

## 4. HeLa 与突变体的直接证据

### 4.1 2012 年：课程核心表型已有直接实现

Roczniak-Ferguson 等使用 HeLa M / 稳定 TFEB-GFP 细胞，Figure 3 展示 EBSS 饥饿、rapamycin、Torin1 条件和核/质比时间过程。Figure 1 则显示溶酶体功能受抑时也可出现 TFEB 核积累；Figure 2 比较 S211A。其结论是定位、14-3-3 结合与磷酸化调控，而不是“看到进核就证明所有下游过程增加”。本次实际读取 PubMed 原始摘要和 Figures 1–4 图注；PMC 网页被验证页阻断，未冒称全文通读。[论文](https://pubmed.ncbi.nlm.nih.gov/22692423/)

### 4.2 2017 年：S211A 不是绝对核内开关

Vega-Rubin-de-Celis 等在 HeLa 显示，S211A 增加核内分布、破坏 YWHA/14-3-3 结合，但仍可分布于核与胞质，并继续响应 Torin1；论文进一步研究 S122 参与的多步骤调控。课程设计若使用 S211A，应称为“核排斥减弱/核分布增加的磷酸化位点突变体”，不能预先承诺其在所有条件下全核定位。本次读取原始摘要、Results 及 Figures 1/4 的索引全文片段。[原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5361595/)，DOI：[10.1080/15548627.2016.1271514](https://doi.org/10.1080/15548627.2016.1271514)。

### 4.3 2018 年：S142/S138 与 S211 的作用可区分

Napolitano 等在 HeLa 使用 TFEB-GFP 野生型与 S142A、S138A、S211A，利用活细胞 FRAP 分开评估核输出。S142A/S138A 的核输出明显受损，S211A 的核输出相对保留，说明“核里更多”不等于同一种机制。本文也记录了营养剥夺后补回营养的设计。仅测固定细胞终点 N/C 比不能区分核输入增加、核输出降低或两者同时改变。本次读取原始 Results、Figures 4/5、Plasmids、Cell treatments、FRAP/FLIP 方法段的索引全文片段。[原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6098152/)

## 5. 哪些实验结果能支持什么结论

| 读出 | 可直接支持 | 单独不能支持 |
|---|---|---|
| EGFP–TFEB 或 TFEB–EGFP 核/质荧光比 | 指定融合蛋白在指定条件下重新分布 | 内源 TFEB 完全同样行为；核输入/输出的具体机制；自噬通量增加 |
| 全细胞 anti-GFP Western blot | 融合蛋白表达及表观大小 | 核定位；天然功能完全保留；通量 |
| 内源 TFEB 免疫染色或核/质分离 | 与内源定位的一致性 | 下游功能必然变化；分离实验还需核/质纯度标记 |
| CLEAR 报告基因或若干 TFEB 靶基因 RT-qPCR | 转录输出发生变化 | 物质最终降解速度一定增加；没有遗传干预时也不能单独证明变化专属于 TFEB |
| 配合适当对照的 LC3 周转、串联荧光 LC3、货物降解读出 | 比单一终点定位更直接评估自噬各环节及通量 | 单一静态 LC3-II 升高或单一 p62 变化仍不足以概括通量 |

**TFEB 进核与自噬通量增加必须区分。** 一个直接反例是 TFEB 可响应溶酶体功能受抑而进核；这可以是补偿反应。Settembre 等 2011 为证明自噬相关功能，除 TFEB 之外还结合了 LC3、抑制剂条件、串联 RFP-GFP-LC3 及长寿命蛋白降解等证据，说明功能层面需要额外读出。[Settembre 2011 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3638014/)

[Klionsky 等 2021 自噬检测指南](https://pubmed.ncbi.nlm.nih.gov/33634751/)可作为方法解释的补充（属于方法共识，并非发现 TFEB 机制的原始研究）。本次只读取其摘要，摘要明确强调多种互补技术；未声称已逐项审阅这份 382 页指南。

## 6. 当前 LaTeX 的后续落实建议（我的判断，不是用户已决定）

1. **保留核心目标的准确边界**：构建并验证具有营养响应定位的 TFEB 荧光报告蛋白。该目标本身足以连通克隆、表达与细胞成像；不必将课程设计扩成完整自噬机制研究。
2. **优先解决方向与参考序列**：明确人 TFEB 转录本、蛋白 isoform、N/C 端标签、接头和 stop；从全 ORF 而不是载体名称核查。已有质粒只作为基准，不能代替自建克隆所需测序。
3. **用机制问题增加设计层次**：在资源允许时，可比较野生型与一个有明确理由的位点突变，或加入饥饿后的营养恢复。两条扩展都有既有文献，不应包装成未报道的新发现。S142A 与 S211A 回答的问题不完全相同。
4. **保留并明确对照目的**：mock 用于背景；EGFP 空载体用于荧光标签/表达背景；同批载体处理用于溶剂影响；各处理条件的细胞状态检查用于排除明显损伤；内源 TFEB 定位作为外源报告蛋白验证。不要把空载体当作“保证融合蛋白功能正常”的充分证据。
5. **控制表达量和取像偏差**：TFEB 过表达本身即可改变下游自噬/溶酶体系统；应预先规定可分析的表达范围、避免饱和、统一成像与背景扣除方法，并检查结论是否被极高表达细胞主导。这些是后续实验方案建议，本次没有测量表达量或制定任意数值阈值。[过表达功能的原始证据](https://pmc.ncbi.nlm.nih.gov/articles/PMC3638014/)
6. **落实已有统计约定**：当前 `methods-cell.tex` 已明确单次实验内的细胞不作为独立生物学重复，也已要求背景校正、eligibility criteria 和背景水平胞质信号处理。下一步是填入实际采样与分析规则；本次没有发现这些原则仍缺失，不应把旧 Word 的不足重复列作当前错误。
