# TFEB 文献调研

更新日期：2026-10-23。

**结论：当前大作业的基础方案已有充分、直接的文献依据。** HeLa 中表达荧光 TFEB、比较营养饥饿与 Torin1 对核/胞质定位的影响，早在 2012 年已有研究；适合作为包含克隆、表达、成像与结果解释的课程设计。

**当前范围按用户决定保持基础方案，不要求很强的创新性。** 时间过程、营养恢复、突变体和额外功能实验作为之后想完善时的备选，不列为这次新增必做项。

当前作业优先精读：

1. [Roczniak-Ferguson et al., 2012](https://doi.org/10.1126/scisignal.2002790)：与当前 HeLa、饥饿/Torin1、荧光定位方案最接近。
2. [Settembre et al., 2012](https://doi.org/10.1038/emboj.2012.32)：补足营养、磷酸化与定位的机制依据。
