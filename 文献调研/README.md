更新日期：2026-10-25。

**结论：当前大作业的基础方案已有充分、直接的文献依据。** HeLa 中表达荧光 TFEB、比较营养饥饿与 Torin1 对核/胞质定位的影响，早在 2012 年已有研究；适合作为包含克隆、表达、成像与结果解释的课程设计。

**用户在 2026-10-25 改为要求“复现 + 研究延伸”。** 当前报告已加入对照、时间过程、突变、救援及功能设计；另以 C 端 S466/S467/S469 三位点、标签和刺激方式为研究问题，新增五个构建和 18 条件矩阵。Paquette 2021 与 Negoita 2026 的证据、开放问题和检索边界见 [机制延伸记录](../docs/10-25%20机制延伸与流程图重绘.md)。3A 和五位点组合已有先例；不把新画图或新文件当作首次发现。
